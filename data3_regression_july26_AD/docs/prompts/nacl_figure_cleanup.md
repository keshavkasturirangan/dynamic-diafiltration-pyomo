## The core goal
**Figure text (axis labels, ticks, legends) should render at approximately the

pub-quality style uses 15–16pt fonts, which, combined with `\includegraphics`

## Why the mismatch happens (the key idea)
matplotlib font sizes are in **points**, but `\includegraphics[width=...]` then
**scales** the figure, multiplying the effective on-page font size by
`(display_width / figure_saved_width)`. So a 4-inch-wide figure with 16pt fonts,
included at the full `\linewidth` (~6.5 in for this doc), renders text at
`16 * 6.5/4 ≈ 26pt`. The same figure in a `0.49\textwidth` minipage (~3.2 in)
renders at `16 * 3.2/4 ≈ 13pt`. That is why sizes look inconsistent.

**The fix: make the display scale ≈ 1 for every figure, and set the font to
~body size.** Concretely:
1. Determine the report's text width. Add a temporary `\the\linewidth` /
   `\showthe\linewidth` (or use the `layouts`/`printlen` package) and read it from
   the log; for 11pt letter + 1in margins it should be ≈ **6.5 in (≈ 469 pt)**.
   The two-up figures sit in `0.49\textwidth` minipages ≈ **3.15 in** each.
2. **Save each figure at a physical `figsize` width equal to its intended display
   width** — full-width figures at ≈ the text width, half-width (minipage) figures
   at ≈ half. Add a helper to `plot_style.py`, e.g. `fig_width("full")` /
   `fig_width("half")` returning inches, and use it for `figsize`.
3. Include each figure at that natural width (`width=\linewidth` inside a matching
   container works, since figure width = container width ⇒ scale ≈ 1).
4. Set `plot_style` fonts to about the body size: **axis labels ~11pt (bold OK),
   tick labels ~9–10pt, legend ~9–10pt**. Keep the other good habits (units in
   bracketed labels, inward ticks with top/right, colorblind palette, one color
   per dataset, PNG+PDF via `bbox_inches='tight'`).
