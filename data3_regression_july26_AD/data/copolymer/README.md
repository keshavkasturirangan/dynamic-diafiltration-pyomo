# Copolymer membrane data (Estrada spacer-arm manuscript)

Source: Box `Diafiltration Modeling and Experiments (Phillip and Dowling groups)/`
`Spacer arm manuscript - Laurianne/` (provided by Laurianne Estrada, 2026-07;
COOH-functionalized copolymer membranes). Staged here for the DATA3 single-salt
workflow on **NaCl (1:1)** and **Na2SO4 (1:2, divalent SO4 co-ion)**.

- `Analysis of Select Data.xlsx` — processed single-salt sheets, standard 15-col
  schema (B=c_int, D=I, F=R, H=c_p, J=Jw, K=B, M=t, N=kappa_r, O=kappa_p), same as the
  NF270 workbooks.
- `PEG0.1.xlsx`, `PEG6.5.xlsx`, `ALK1.2.xlsx` — raw campaign workbooks (NF270 raw
  format) for the four focus datasets.
- `Spacer_arm_SI.docx` — manuscript SI: zeta-potential fixed-charge density chi
  (Section S2 / Table S1) and water volume fraction phi_w (Section S5 / Table S3),
  used to validate the regressed chi and to set the membrane diffusivities.

**Four focus datasets (all unadjusted pH 6):** `PEG0.1 6.18.24NaCl`,
`PEG6.5 6.27.24NaCl (2)`, `PEG0.1 8.5.24Na2SO4`, `ALK1.2 5.7.25Na2SO4`.

Note: `Spacer_arm_SI.docx` is from a manuscript under submission — kept here only for
provenance/validation values; gitignore it if that is preferred.
