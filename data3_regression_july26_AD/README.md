# data3_regression

Regression analysis of multicomponent nanofiltration / diafiltration data for the
**DATA3** project — a collaboration between the **Dowling Lab** and the **Phillip
(W.A.T.E.R.) Lab** at the University of Notre Dame.

We characterize surface-charged NF270 membranes from single-salt diafiltration
experiments (NaCl, CaCl₂, LaCl₃) by regressing the membrane **fixed charge
density** `χ` and a thermodynamic **partition factor** `δ*` from a
Donnan-equilibrium membrane model, then extend the approach to multicomponent
(multi-salt) systems. The analysis is being ported from the collaborators'
original MATLAB prototype to Python (scipy → Pyomo/ParmEst).

## Environment setup

The analysis runs in a dedicated conda environment named **`data3-regression`**,
specified by [`environment.yml`](environment.yml). It covers the scipy regression
(Step 2) through the Pyomo/ParmEst + Ipopt work (Steps 3–5).

### Create the environment

```bash
# from the repository root
conda env create -f environment.yml
conda activate data3-regression
```

If `conda` is not on your `PATH`, call it by its full path (e.g.
`/opt/anaconda3/bin/conda`) or run `conda init` once for your shell.

### Update the environment (after editing `environment.yml`)

```bash
conda env update -f environment.yml --prune
```

### Remove / recreate

```bash
conda env remove -n data3-regression
conda env create -f environment.yml   # rebuild from scratch
```

### Exact-version reproduction (optional)

`environment.yml` uses loose pins for portability across machines/OSes. To
capture the exact resolved versions on a working machine (e.g. to hand off a
byte-for-byte replica), export a lock file:

```bash
conda env export -n data3-regression --no-builds > environment.lock.yml
```

and recreate elsewhere with `conda env create -f environment.lock.yml`.

> **Note on HSL solvers.** The DATA2 workflow used Ipopt with the HSL MA97 linear
> solver, which is licensed separately. `environment.yml` installs conda-forge
> Ipopt with the (free) MUMPS solver, which is sufficient here. If you have HSL
> available (e.g. the group's `ipopt-hsl-pyomo` env), you can point Ipopt at it.

## Running the analysis

Activate the environment, then run a step's script, e.g.:

```bash
conda activate data3-regression
python analysis/step2_nacl/regress_nacl.py
```

See each step's `README.md` under `analysis/` for details and results.
