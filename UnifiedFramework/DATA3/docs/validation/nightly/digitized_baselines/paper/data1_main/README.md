# DATA1 Main Paper Digitized CSVs

These CSVs are first-pass raster digitizations generated from the extracted
embedded figures in the DATA1 main paper. They are intended as reproducible
paper-side baselines for follow-up cleanup, not as a claim of perfect manual
WebPlotDigitizer-quality extraction.

Conventions:
- one CSV per panel,
- `series_family` groups colored traces/markers,
- `x_data` and `y_data` are derived from manual panel calibration,
- contour figures export trace clouds by color family rather than labeled
  contour values,
- red triangle reference markers are included under the `red` family where present.
